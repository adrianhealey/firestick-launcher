# TV Home

A simple, ad-free home screen for Amazon Fire TV sticks.

- Clock and date, a Favourites row and an All apps grid
- Press and hold Select (or ☰) on an app to add, move, hide or remove it
- An accessibility service sends the Home button here instead of the Amazon home screen

Every push to `main` builds a signed APK and publishes it as the latest release:
`https://github.com/adrianhealey/firestick-launcher/releases/latest/download/tvhome.apk`
